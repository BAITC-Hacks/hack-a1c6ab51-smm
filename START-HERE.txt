КАК ЗАПУСТИТЬ ALEM

1. Распакуйте весь архив в обычную папку.
2. Установите Node.js 22.9 или новее: https://nodejs.org
3. На Windows откройте START-WINDOWS.cmd двойным щелчком.
   На macOS/Linux: откройте терминал в папке проекта и выполните node start.mjs.
4. Откройте http://localhost:3210 (или адрес, указанный сервером).
5. Не закрывайте окно сервера во время работы.

Не открывайте public/index.html напрямую. Этот проект требует Node-сервера.
Live Server и GitHub Pages не поддерживают его серверную часть.

Первый запуск создаст .env из шаблона. Без ключа сайт работает в деморежиме.
Для OpenAI впишите ключ в OPENAI_API_KEY в .env и перезапустите сервер.
Не загружайте .env на GitHub и не отправляйте ключ в чат.

Если порт занят, остановите предыдущий сервер или задайте PORT=3212 в .env
и откройте http://localhost:3212.
