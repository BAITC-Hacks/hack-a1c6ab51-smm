Alem — запуск приложения

Если сайт не загрузился, запустите сервер:

  1. Полностью распакуйте ZIP-архив.
  2. В папке проекта откройте START-WINDOWS.cmd или выполните node start.mjs.
  3. Откройте адрес, который покажет сервер: обычно http://localhost:3210.

Оставьте окно сервера открытым. Прямое открытие index.html, Live Server и GitHub Pages не запускают серверную часть этого приложения.

Требуется Node.js 22.9 или новее. Без API-ключа доступен деморежим.
