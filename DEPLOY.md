# Публикация без установки программ у посетителей

Подготовлена конфигурация Render. Публикация ещё не выполнена: нужен вход владельца в Render и доступ к репозиторию команды.

## Бесплатная демонстрация

1. Загрузите актуальные исходники, включая render.yaml, в корень командного GitHub-репозитория.
2. Войдите на https://dashboard.render.com и подключите GitHub-репозиторий команды.
3. Создайте Blueprint из render.yaml. Проверьте, что выбран Free, до подтверждения.
4. Укажите OPENAI_API_KEY в секретных переменных Render. Не в файлах GitHub.
5. После успешного развёртывания откройте URL сервиса из Render. Посетителям достаточно браузера, Node.js им не нужен.

Альтернатива Blueprint: New → Web Service → репозиторий → ветка main; Build Command: `node --check server.mjs`; Start Command: `node server.mjs`; HOST=0.0.0.0; AI_PROVIDER=openai; OPENAI_MODEL=gpt-4.1-mini; OPENAI_API_KEY в секретах. PORT задаёт Render. Не используйте GitHub Pages: проект имеет серверную часть.

## Ограничения демонстрации

Free использует временную файловую систему: созданные задачи, отклики и баллы сбрасываются при перезапуске или новой публикации. Исходные тестовые данные восстанавливаются автоматически. Сервис может засыпать без запросов; первый запуск по ссылке может занять время.

Для постоянных данных используйте платный сервис с Persistent Disk: mount path `/var/data`, переменная DATA_DIR=/var/data/alem. Тариф и стоимость подтвердите самостоятельно до создания платного ресурса. Автоматически платные ресурсы не созданы.

Это публичная общая демонстрация с переключением ролей, без индивидуальных аккаунтов и проверки владельца задачи. Все посетители могут изменять демонстрационные данные. Для реальной работы организаций требуется авторизация. Сервер ограничивает число AI-операций до 30 в час на весь процесс (каждый анализ использует два вызова модели); лимит можно задать через AI_HOURLY_LIMIT. Это дополнительный ограничитель, а не финансовый лимит аккаунта OpenAI.

При необходимости задайте PUBLIC_ORIGIN равным полному https-адресу сайта. Сервер поддерживает HTTPS за прокси; API-ключ хранится только на сервере.

Документация: https://render.com/docs/web-services и https://render.com/docs/disks
